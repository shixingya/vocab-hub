# vocab-hub
它是面向全年龄段学习者打造的趣味化单词自学平台，彻底改变传统背单词枯燥低效的痛点，用游戏化交互方式重塑词汇学习体验。平台拥有高度灵活的词库拓展体系，初始上线专业托业高频词汇资源，后续持续更新雅思、托福、四六级等全套学习词库，同时支持自定义词库导入，满足不同人群、不同阶段的学习需求。平台独创两大特色学习模式，单词射击闯关玩法强化视觉记忆，听音识词模式锻炼听力语感，搭配难度分级、学习数据记录、错题复盘、打卡激励等功能，让学习更有成就感。项目采用纯静态网页架构，轻量化无广告、无付费内容，打开即可使用，部署简单、运行流畅。整体学习氛围轻松温和，不内卷、不施压，依托碎片化学习逻辑，帮助用户循序渐进积累核心词汇，扎实提升英语基础，无论是应试备考还是日常英语能力提升，都能提供高效、趣味、便捷的自学助力。
